# Ateliê Memória — portfólio fotográfico

Site estático e responsivo. Abra `index.html` para conferir os arquivos localmente.

## Publicar na Vercel

1. Na Vercel, importe o repositório `luizmk7/FOTOGRAFIA`.
2. Selecione **Other** em *Framework Preset*.
3. Mantenha **Root Directory** na raiz e **Build Command** vazio. A pasta de saída é a própria raiz (`.`).
4. Publique. Não é necessário instalar dependências nem executar um build.

## Personalização

- O nome, a apresentação e o texto das seções estão em `index.html`.
- As cores, tipografia e espaçamentos estão em `assets/style.css`.
- Os textos das coleções e a interação da galeria estão em `assets/app.js`.
- Substitua as imagens `assets/*.webp` por fotografias reais com autorização dos titulares. Preserve os nomes ou altere também os caminhos no HTML e no JavaScript.
- Os planos descrevem o escopo sem preços fictícios. Ajuste as opções e insira valores reais conforme o profissional.
- O formulário monta e copia uma mensagem, mas não a envia; para receber pedidos diretamente, configure um endereço profissional, WhatsApp ou integração de formulário antes de publicar para clientes.

Marca, nome, biografia e imagens desta demonstração são ilustrativos.
